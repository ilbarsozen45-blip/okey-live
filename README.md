# ILBARSDOWS

ILBARSDOWS, UEFI tabanlı deneysel bir işletim sistemi araştırma projesidir.

## Modüller
- `bootloader`: UEFI yükleyici (C / GNU-EFI)
- `kernel`: Çekirdek (C + C++)
- `drivers`: Donanım soyutlama ve temel sürücüler
- `fs`: ILBFS özel dosya sistemi
- `ui`: Framebuffer tabanlı modern masaüstü bileşenleri
- `apps`: Yerleşik kullanıcı alanı uygulamaları
- `lib`: Ortak yardımcı kütüphane
- `build` / `scripts`: derleme ve ISO üretim boru hattı

> Bu depo, modüler ve ölçeklenebilir bir OS mimarisini göstermek için organize edilmiştir.
